# Contributing

## Setup

Rust stable via rustup, plus the C/C++ and library toolchain that `highs-sys` and the
NetCDF I/O need:

- cmake (>= 3.16) and a C++ compiler — builds HiGHS from source;
- libclang (for the bindgen step of `highs-sys`; set `LIBCLANG_PATH` if it is not in a
  default location);
- NetCDF and HDF5 development libraries (`libnetcdf-dev`, `libhdf5-dev` on Debian/Ubuntu).

For the parity oracle and the Python bindings you additionally need the Calliope
reference checkout at `../calliope` (its pixi dev environment) and Python >= 3.11 with
maturin.

## Checks

```bash
cargo fmt --check
cargo clippy --workspace --all-targets -D warnings
cargo test --workspace
```

`unsafe` is confined to `crates/calliope-highs/src/ffi.rs`; keep it that way. Lints are
set workspace-wide in the root `Cargo.toml` (`unsafe_code = "forbid"`, clippy `warn` +
CI `-D warnings`).

## Parity

Behaviour is pinned against Calliope 0.7.0:

- `golden/` holds the golden files (inputs, LP, results) generated by `oracle/golden.py`;
- `cargo run -p xtask -- parity` re-runs every fixture and compares; `--self-check`
  verifies the harness itself;
- differences that will not be fixed are classified in `crates/xtask/src/known.rs` with
  a documented reason, and every classification is re-verified on each run;
- LP equality uses `cargo run -p xtask -- lp-diff` (canonicalised CPLEX-LP comparison).

A change is complete when parity stays green, or the new difference is classified with a
reason in `crates/xtask/src/known.rs` and `docs/findings.md`.

## The Python reference

Tests that compare against Python Calliope look for the checkout at `../calliope`
(override with `CALLIOPE_REFERENCE`) and skip when it is absent, so plain
`cargo test --workspace` works without Python. The oracle environment is created in
`../calliope` with `pixi` (see `oracle/`).
